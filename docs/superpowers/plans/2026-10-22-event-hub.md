# Event Hub Restructure Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the site into a three-tier maritime events hub: anchor (Maritime Expo Asia 2027), co-hosted events on a shared template, and listed events, with a `/partner` page and leads tagged by event.

**Architecture:** `events.featured` becomes `events.tier` (`anchor` / `cohosted` / `listed`, one anchor enforced by a unique index). Pure logic (`sortEvents`, `eventHref`, `tierBadge`, `selectHomeEvents`, `pickEventSlug`) lives in `lib/` and is unit-tested. Pages stay static: home data comes from one `'use cache'` function tagged `events`. Co-hosted events are code-built static routes under `/events/<slug>`, which take priority over the generic `[slug]` page.

**Tech Stack:** Next.js 16.4 (App Router, `cacheComponents: true`), Supabase Postgres, `node --test`.

**Spec:** `docs/superpowers/specs/2026-10-22-event-hub-design.md`

## Global Constraints

- Work on `feat/events-calendar` (or a branch cut from it). Read `node_modules/next/dist/docs/` before using a Next API you have not used in this repo.
- Tier values exactly: `anchor`, `cohosted`, `listed`. Badges exactly: `Our event` (anchor), `Co-hosted` (cohosted), none for listed.
- Anchor slug `maritime-expo-asia-2027`, anchor path `/maritime-expo-asia-2027`. Co-hosted Summit path `/events/sarawak-maritime-industry-summit-2027`.
- Permanent redirects: `/summit-2027` to `/events/sarawak-maritime-industry-summit-2027`; `/events/maritime-expo-asia-2027` to `/maritime-expo-asia-2027`.
- Nav exactly: `Expo 2027` · `Events` · `Partner with us` · `Contact` (mobile menu also `Register interest` to `/#register`).
- New enquiry types exactly `cohost` and `listing`. Listing extra fields: `event_name`, `event_dates`, `event_location`, `event_website`. Co-host has no extra fields.
- `CLAUDE.md` content rules apply to all copy (no VIP names, no prices, `[TBC]` hidden, no invented facts). British spelling.
- The service role key is still missing from `.env.local`: verify database changes by DO-block role simulation through Supabase MCP `execute_sql` (rolled back by raising), and update the node tests so they pass once the key exists.
- No new dependencies.

## Review Focus

1. Old shared links with a query, e.g. `/summit-2027?type=exhibitor#enquire`, must land on the new Summit page with the Exhibit form chosen (redirect keeps the query). (Task 5 curl check.)
2. A tampered or stale hidden `event` field (unknown slug, a hidden or pending event) must still save the lead, untagged, never fail the form. (Task 3 `pickEventSlug` tests.)
3. Choosing `anchor` for a second event in `/admin/events` must show `Only one event can be the anchor.`, not a generic error. (Task 2 `describeEventError` test; Task 1 SQL check.)
4. When no co-hosted event is upcoming (after March 2027) or no dated listed events exist, the home sections must disappear, not show empty headings. (Task 2 `selectHomeEvents` tests; Task 6 manual check.)
5. `/events/maritime-expo-asia-2027` (the old generic page, still produced by `[slug]`) must redirect, not serve a duplicate anchor page. (Task 4 curl check.)
